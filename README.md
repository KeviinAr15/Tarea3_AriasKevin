## Cómo reproducir
1. Clonar este repositorio y abrir la carpeta (o el `.Rproj` )
2. Clonar la base del profesor en la carpeta `base/`:

3. Correr `source("cod/01_datos.R")` desde la raíz para generar `data/` y `config/`
4. Renderizar `Tarea3_AriasKevin.qmd` para obtener el `.html`.
